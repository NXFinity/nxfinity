## 🌐 Meta EN|IX: Production-Ready Social Platform

> **Meta EN|IX** is a comprehensive social platform built with NestJS and Next.js, featuring user management, authentication, real-time communication, content management, and a developer API with OAuth 2.0 support.

### 🛠 Built With:

**Backend:**
- **NestJS** v11.0.1 - Progressive Node.js framework
- **TypeScript** - Type-safe JavaScript
- **PostgreSQL** - Relational database with TypeORM
- **Redis** - Caching and session management
- **Socket.IO** - Real-time WebSocket communication

**Frontend:**
- **Next.js** 16.0.3 - React framework with server-side rendering
- **React** 19.2.0 - Modern UI library
- **Tailwind CSS** v4 - Utility-first styling
- **TanStack Query** - Data fetching and state management

### ✨ Key Features:

- ✅ User profiles, privacy controls, and account management
- ✅ Two-factor authentication (2FA) and OAuth 2.0
- ✅ Real-time communication via WebSockets
- ✅ Content management (posts, comments, likes, shares)
- ✅ Developer API with OAuth 2.0 integration
- ✅ User analytics and engagement metrics
- ✅ Digital Ocean Spaces integration for media storage, with AWS S3 support.
